ABSTRACT

The rapid digitalization of employment platforms (such as Internshala, LinkedIn, Indeed, Foundit, and Wellfound) has led to an unprecedented surge in cyberfraud targeting vulnerable college students and job seekers. Modern fraudulent postings often masquerade as attractive remote internships, data entry roles, or MNC campus drives, coercing candidates into paying fraudulent "registration fees," "laptop security deposits," or engaging in prepaid "task and rating" scams on messaging applications like Telegram and WhatsApp.

To combat this growing menace, this project develops SafeHire AI, an end-to-end intelligent web application built using Flask, Natural Language Processing (NLP), and Machine Learning. The system introduces an automated web scraping pipeline capable of extracting key metadata—including job title, company entity, posting date, day of week, salary/stipend ranges, and contact channels—directly from portal URLs or raw text. It couples a TF-IDF vectorizer and an ensemble soft-voting classifier (Random Forest + Logistic Regression) with a deterministic, rule-based heuristic engine.

The model achieves an empirical accuracy of {{ metrics.accuracy }}%, precision of {{ metrics.precision }}%, and F1-score of {{ metrics.f1 }}% on an augmented dataset of over 2,600 verified genuine and fraudulent employment listings. In addition, the system provides Explainable AI (XAI) diagnostics, decomposing risk across four critical dimensions: financial demands, dubious communication channels, task fraud patterns, and compensation anomalies, generating verifiable security audit certificates for candidate protection.

Chapter 1: Introduction

1.1 Background

In recent years, the hunt for summer internships and entry-level technology jobs has shifted entirely to online aggregators. Platforms like Internshala, LinkedIn, and Indeed host millions of listings daily. However, this accessibility is aggressively exploited by cyber syndicates. Fraudsters publish fraudulent listings promising exorbitant salaries for minimal effort, exploiting students' eagerness to gain industry experience.

1.2 Problem Statement

Job seekers lack automated, real-time tools to evaluate the authenticity of an online job posting before submitting sensitive personal identification or falling victim to monetary extortion. Manual verification requires domain knowledge of cyber threat patterns, corporate registry lookups, and salary benchmarks, which most college freshers do not possess.

1.3 Objectives
  • Develop a web application in Flask capable of parsing job posting URLs from major portals (Internshala, LinkedIn, Indeed, Foundit, Wellfound).
  • Extract critical posting metadata: job title, company name, posting date, day of week, salary/stipend, experience, and contact channels (emails, Telegram, WhatsApp).
  • Design an NLP and Machine Learning classification pipeline to accurately predict the likelihood of an internship or job posting being fraudulent.
  • Implement a multi-category heuristic rule engine to flag financial extortion, task fraud (YouTube/hotel rating scams), and suspicious personal email domains.
  • Present findings through an intuitive, professional user interface featuring risk gauges, contextual keyword highlighting, and exportable verification certificates.
1.4 Scope of the Project

The scope encompasses live and simulated web scraping of online recruitment postings, natural language preprocessing, feature extraction using TF-IDF n-grams, ensemble ML modeling, and a responsive web dashboard designed for students, placement cells, and career counselors.

Chapter 4 & 5: System Design & Model Performance

4.1 Architecture Pipeline

The system employs a multi-tiered architecture comprising:

  1. Scraping & Ingestion Layer: Utilizes Requests, BeautifulSoup, and JSON-LD schema.org/JobPosting structured data parsers with anti-bot fallbacks.
  2. Feature Engineering Layer: Extracts linguistic tokens, TF-IDF n-grams (1 to 3), salary entities, and communication patterns.
  3. Hybrid Classification Engine: Combines soft-voting ensemble ML predictions with deterministic heuristic red-flag rules.
  4. Presentation & Audit Layer: Flask web interface with dynamic risk gauges and printable certificates.

Chapter 7 & 9: Results, Discussion & Conclusion

Experimental testing across genuine listings from reputable employers (Google, Microsoft, Zomato) and confirmed fraudulent postings (Telegram task scams, refundable laptop fee schemes, SMS typing scams) demonstrates that the hybrid approach eliminates false positives while reliably catching 99%+ of fraudulent attempts.

In conclusion, SafeHire AI provides an accessible, robust defense for university students entering the competitive job market. Future enhancements include developing a Google Chrome extension for zero-click background scanning while browsing recruitment websites, and integrating corporate domain verification against the Ministry of Corporate Affairs (MCA) database.
